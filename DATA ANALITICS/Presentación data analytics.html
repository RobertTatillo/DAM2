Fundamentos y Herramientas

¿Qué es Data Analytics?

El análisis de datos es el proceso de examinar, limpiar, transformar y modelar datos para descubrir información útil, llegar a conclusiones y apoyar la toma de decisiones.

En términos simples:

  • Recopilar datos de diferentes fuentes
  • Limpiar y organizar esos datos
  • Analizar patrones y tendencias
  • Visualizar los resultados
  • Tomar decisiones basadas en evidencia

Diferencias Clave

📊 Data Analytics

  • Objetivo: Entender qué pasó y por qué
  • Enfoque: Descriptivo y diagnóstico
  • Herramientas: Excel, Python, SQL, Tableau
  • Ejemplo: "Las ventas bajaron 15% en diciembre"

🔬 Data Science

  • Objetivo: Predecir qué pasará
  • Enfoque: Predictivo y prescriptivo
  • Herramientas: Python, R, ML, Big Data
  • Ejemplo: "Las ventas bajarán 10% el próximo mes"

🤖 Machine Learning

  • Objetivo: Automatizar predicciones
  • Enfoque: Algoritmos que aprenden
  • Herramientas: TensorFlow, PyTorch, Scikit-learn
  • Ejemplo: "Sistema que predice automáticamente"

Jupyter Notebooks (.ipynb)

Un Jupyter Notebook es un documento interactivo que permite combinar código ejecutable, texto explicativo, ecuaciones matemáticas y visualizaciones en un solo lugar.

Características principales:

📝 Interactivo
Ejecuta código línea por línea
📚 Documentado
Mezcla código con explicaciones
🔄 Reproducible
Otros pueden ejecutar tu trabajo
📊 Visual
Gráficos integrados en el documento

Extensión: .ipynb (Interactive Python Notebook)

Componentes de un Notebook

1. Celdas de Código

# Ejemplo de celda de código import pandas as pd datos = [1, 2, 3, 4, 5] promedio = sum(datos) / len(datos) print(f"El promedio es: {promedio}")

2. Celdas de Markdown (Texto)

# Título Principal

## Subtítulo

Texto normal con **negrita** y *cursiva*

- Lista de elementos
- Otro elemento

3. Outputs (Resultados)

  • Texto impreso por print()
  • Gráficos y visualizaciones
  • Tablas de datos
  • Mensajes de error

¿Por qué usar Notebooks?

✅ Ventajas

  • Experimentación rápida
  • Documentación integrada
  • Visualización inmediata
  • Fácil compartir resultados
  • Ideal para análisis exploratorio
  • Reproducibilidad

⚠️ Limitaciones

  • No ideal para aplicaciones grandes
  • Control de versiones más complejo
  • Puede volverse desordenado
  • Dependiente del orden de ejecución
💡 Los notebooks son perfectos para Data Analytics, donde la exploración y documentación son clave

Configuración del Entorno

🔧 Preparación en VSCode:

  1. Instalar Python (versión 3.8 o superior)
  2. Instalar VSCode
  3. Instalar extensiones:
    • Python
    • Jupyter
    • Python Docstring Generator
  4. Instalar librerías básicas:
    pip install pandas numpy matplotlib seaborn jupyter

☁️ Uso de Google Colab:

  1. Acceder a colab.research.google.com
  2. Iniciar sesión con cuenta de Google
  3. Crear nuevo notebook
  4. ¡Listo para empezar!

Primeros Pasos con Notebooks

Operaciones básicas:

Shift + Enter
Ejecutar celda
A / B
Insertar celda arriba/abajo
M / Y
Cambiar a Markdown/Code
DD
Eliminar celda

Estructura recomendada de un notebook:

  1. Título y descripción (Markdown)
  2. Imports de librerías
  3. Carga de datos
  4. Exploración inicial
  5. Análisis y visualizaciones
  6. Conclusiones (Markdown)
