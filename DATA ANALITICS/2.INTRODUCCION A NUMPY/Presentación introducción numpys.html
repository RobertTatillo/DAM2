Arrays y Operaciones Matemáticas Eficientes

¿Qué es NumPy?

NumPy (Numerical Python) es la librería fundamental para computación científica en Python. Proporciona arrays multidimensionales eficientes y herramientas para trabajar con ellos.

Características principales:

  • 🔢 Arrays N-dimensionales: Estructuras de datos homogéneas y eficientes
  • ⚡ Operaciones vectorizadas: Cálculos rápidos sin bucles explícitos
  • 🧮 Funciones matemáticas: Trigonometría, álgebra lineal, estadística
  • 🔗 Interoperabilidad: Base para Pandas, Matplotlib, Scikit-learn
  • 💾 Eficiencia de memoria: Almacenamiento optimizado de datos numéricos
  • 🌐 Estándar de la industria: Usado en ciencia, ingeniería y finanzas

¿Por qué es importante NumPy?

Es el fundamento de todo el ecosistema científico de Python. Sin NumPy, no existirían Pandas, Matplotlib, Scikit-learn ni la mayoría de librerías de análisis de datos.

NumPy vs Python Básico

🐍 Listas de Python

  • Tipo: Heterogéneas (cualquier tipo)
  • Memoria: No optimizada
  • Operaciones: Requieren bucles
  • Velocidad: Lenta para cálculos
  • Funciones: Básicas
# Multiplicar por 2 lista = [1, 2, 3, 4, 5] resultado = [] for x in lista: resultado.append(x * 2) # [2, 4, 6, 8, 10]

  • Velocidad: Hasta 100x más rápido
  • Funciones: Cientos de funciones matemáticas
# Multiplicar por 2 import numpy as np array = np.array([1, 2, 3, 4, 5]) resultado = array * 2 # [2 4 6 8 10]

Arrays de NumPy

¿Qué es un Array?

Un array es una colección de elementos del mismo tipo, organizados en una estructura multidimensional

Array 1D (Vector)

1 2 3 4 5

Array 2D (Matriz)

1 2 3
4 5 6

Creando arrays:

import numpy as np # Desde una lista arr1d = np.array([1, 2, 3, 4, 5]) print(arr1d) # [1 2 3 4 5] # Array 2D desde lista de listas arr2d = np.array([[1, 2, 3], [4, 5, 6]]) print(arr2d) # [[1 2 3] # [4 5 6]] # Arrays especiales zeros = np.zeros(5) # [0. 0. 0. 0. 0.] ones = np.ones(3) # [1. 1. 1.] rango = np.arange(0, 10, 2) # [0 2 4 6 8]

Propiedades de los Arrays

📐

Shape (Forma)

arr = np.array([[1, 2, 3], [4, 5, 6]]) print(arr.shape) # (2, 3) # 2 filas, 3 columnas
🏷️

Dtype (Tipo)

arr_int = np.array([1, 2, 3]) print(arr_int.dtype) # int64 arr_float = np.array([1.0, 2.0]) print(arr_float.dtype) # float64
📏

Size (Tamaño)

arr = np.array([[1, 2, 3], [4, 5, 6]]) print(arr.size) # 6 elementos print(arr.ndim) # 2 dimensiones
🔄

Reshape (Cambiar forma)

arr = np.arange(6) # [0 1 2 3 4 5] arr_2d = arr.reshape(2, 3) # [[0 1 2] # [3 4 5]]

Ejemplo práctico:

# Crear array de datos de ventas ventas = np.array([100, 150, 200, 120, 180, 90, 250]) print(f"Forma: {ventas.shape}") # (7,) print(f"Tipo: {ventas.dtype}") # int64 print(f"Número de elementos: {ventas.size}") # 7 print(f"Dimensiones: {ventas.ndim}") # 1 # Convertir a matriz 7x1 ventas_2d = ventas.reshape(7, 1) print(f"Nueva forma: {ventas_2d.shape}") # (7, 1)

Operaciones con Arrays

Operaciones Aritméticas Elementales

Suma
a = np.array([1, 2, 3]) b = np.array([4, 5, 6]) print(a + b) # [5 7 9]
Multiplicación
a = np.array([1, 2, 3]) print(a * 2) # [2 4 6] print(a * a) # [1 4 9]
Comparaciones
a = np.array([1, 2, 3, 4]) print(a > 2) # [False False True True]
Funciones Math
a = np.array([0, 1, 2, 3]) print(np.sqrt(a)) print(np.sin(a))

Ejemplo con datos reales:

# Datos de temperatura en Celsius temp_celsius = np.array([20, 25, 30, 15, 22]) # Convertir a Fahrenheit: F = C * 9/5 + 32 temp_fahrenheit = temp_celsius * 9/5 + 32 print(f"Celsius: {temp_celsius}") print(f"Fahrenheit: {temp_fahrenheit}") # Encontrar días calurosos (>25°C) dias_calurosos = temp_celsius > 25 print(f"Días calurosos: {dias_calurosos}") # Temperatura promedio promedio = np.mean(temp_celsius) print(f"Temperatura promedio: {promedio}°C")

Funciones Útiles de NumPy

📊

Estadísticas

arr = np.array([1, 2, 3, 4, 5]) print(np.mean(arr)) # 3.0 print(np.median(arr)) # 3.0 print(np.std(arr)) # 1.58 print(np.min(arr)) # 1 print(np.max(arr)) # 5 print(np.sum(arr)) # 15
🔍

Búsqueda

arr = np.array([3, 1, 4, 1, 5]) print(np.argmax(arr)) # 4 (índice del máximo) print(np.argmin(arr)) # 1 (índice del mínimo) print(np.where(arr > 3)) # (array([2, 4]),) print(np.unique(arr)) # [1 3 4 5]
🎲

Números Aleatorios

# Números aleatorios entre 0 y 1 print(np.random.random(3)) # Enteros aleatorios print(np.random.randint(1, 10, 5)) # Distribución normal print(np.random.normal(0, 1, 3))
✂️

Indexing y Slicing

arr = np.array([0, 1, 2, 3, 4, 5]) print(arr[2]) # 2 print(arr[1:4]) # [1 2 3] print(arr[-1]) # 5 print(arr[::2]) # [0 2 4]

Ejemplo de análisis de ventas:

# Datos de ventas mensuales ventas = np.array([1200, 1500, 1100, 1800, 2000, 1600, 1900, 2200, 1700, 1400, 1300, 2500]) meses = np.array(['Ene', 'Feb', 'Mar', 'Abr', 'May', 'Jun', 'Jul', 'Ago', 'Sep', 'Oct', 'Nov', 'Dic']) # Análisis estadístico print(f"Ventas promedio: {np.mean(ventas):.2f}") print(f"Mes con mayores ventas: {meses[np.argmax(ventas)]}") print(f"Mes con menores ventas: {meses[np.argmin(ventas)]}") # Meses con ventas superiores al promedio promedio = np.mean(ventas) meses_buenos = meses[ventas > promedio] print(f"Meses con ventas superiores al promedio: {meses_buenos}")

NumPy: La Base del Ecosistema

🐼

Pandas

Los DataFrames de Pandas están construidos sobre arrays de NumPy. Todas las operaciones numéricas en Pandas usan NumPy internamente.

📈

Matplotlib

Las gráficas de Matplotlib reciben arrays de NumPy como datos de entrada para crear visualizaciones.

🤖

Scikit-learn

Todos los algoritmos de machine learning esperan datos en formato de arrays de NumPy.

🧠

TensorFlow/PyTorch

Los frameworks de deep learning son compatibles con NumPy y pueden convertir entre sus formatos.

Ejemplo de integración:

import numpy as np import pandas as pd import matplotlib.pyplot as plt # 1. Datos en NumPy datos_numpy = np.array([10, 20, 30, 40, 50]) # 2. Convertir a Pandas df = pd.DataFrame({ 'valores': datos_numpy, 'cuadrados': datos_numpy ** 2 }) # 3. Visualizar con Matplotlib plt.plot(datos_numpy, datos_numpy ** 2) plt.title('Función Cuadrática') plt.show() # Todo funciona perfectamente integrado!
🔗 NumPy es el "pegamento" que une todo el ecosistema científico de Python

¿Por qué aprender NumPy antes de Pandas?

🎯 Comprensión profunda

  • Entender cómo funciona Pandas internamente
  • Depurar problemas de rendimiento
  • Optimizar operaciones complejas
  • Usar funciones específicas cuando sea necesario

⚡ Mejor rendimiento

  • Operaciones vectorizadas más eficientes
  • Menor overhead para cálculos simples
  • Control directo sobre memoria
  • Integración con bibliotecas de bajo nivel

Cuándo usar NumPy vs Pandas:

✅ Usar NumPy cuando:

  • Trabajas principalmente con datos numéricos
  • Necesitas operaciones matemáticas complejas
  • El rendimiento es crítico
  • Trabajas con arrays multidimensionales
  • Integras con bibliotecas científicas

✅ Usar Pandas cuando:

  • Trabajas con datos tabulares (como Excel)
  • Necesitas etiquetas de filas y columnas
  • Manejas diferentes tipos de datos
  • Realizas análisis exploratorio de datos
  • Lees/escribes archivos CSV, Excel, etc.
🧠 NumPy + Pandas = Herramientas complementarias para análisis completo
