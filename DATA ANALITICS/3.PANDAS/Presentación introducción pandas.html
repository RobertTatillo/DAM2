Manipulación y Análisis de Datos en Python

¿Qué es Pandas?

Pandas es la librería más importante de Python para manipulación y análisis de datos. Su nombre viene de "Panel Data" y proporciona estructuras de datos potentes y herramientas de análisis fáciles de usar.

Características principales:

  • 📊 Estructuras de datos flexibles: Series y DataFrames
  • 🔧 Manipulación de datos: Filtrado, agrupación, transformación
  • 📁 Lectura de archivos: CSV, Excel, JSON, SQL y más
  • 🧹 Limpieza de datos: Manejo de valores nulos y duplicados
  • 📈 Análisis estadístico: Estadísticas descriptivas y agregaciones
  • ⚡ Alto rendimiento: Optimizado para grandes volúmenes de datos

¿Por qué usar Pandas?

Es como Excel, pero mucho más poderoso: Mientras Excel tiene límites de filas y funcionalidades, Pandas puede manejar millones de registros y realizar análisis complejos de forma automatizada.

Pandas vs Excel vs Python Básico

📊 Excel

  • Límites: ~1M filas máximo
  • Interface: Gráfica, punto y clic
  • Automatización: Limitada (macros)
  • Aprendizaje: Fácil para comenzar
  • Colaboración: Archivos compartidos
  • Análisis: Básico a intermedio

🐼 Pandas

  • Límites: Millones de filas
  • Interface: Código programático
  • Automatización: Total y reproducible
  • Aprendizaje: Curva moderada
  • Colaboración: Control de versiones
  • Análisis: Avanzado y personalizado

🐍 Python Básico

  • Estructuras: Listas y diccionarios
  • Operaciones: Bucles manuales
  • Rendimiento: Lento para datos grandes
  • Código: Mucho código para tareas simples
  • Análisis: Requiere implementación manual
💡 Pandas combina la facilidad de Excel con el poder de la programación

Estructuras de Datos en Pandas

1. Series - Datos Unidimensionales

Una Series es como una columna de Excel con superpoderes

import pandas as pd # Crear una Series ventas = pd.Series([100, 150, 200, 120, 180]) print(ventas)
0 100 1 150 2 200 3 120 4 180 dtype: int64

2. DataFrame - Datos Bidimensionales

Un DataFrame es como una hoja de Excel completa

Producto Ventas Precio
0 Laptop 100 800
1 Mouse 150 25
2 Teclado 200 50

Creando DataFrames

Método 1: Desde un diccionario

import pandas as pd datos = { 'nombre': ['Ana', 'Juan', 'María', 'Carlos'], 'edad': [25, 30, 35, 28], 'ciudad': ['Madrid', 'Barcelona', 'Valencia', 'Sevilla'], 'salario': [30000, 45000, 50000, 38000] } df = pd.DataFrame(datos) print(df)

Método 2: Desde una lista de listas

datos = [ ['Ana', 25, 'Madrid', 30000], ['Juan', 30, 'Barcelona', 45000], ['María', 35, 'Valencia', 50000] ] columnas = ['nombre', 'edad', 'ciudad', 'salario'] df = pd.DataFrame(datos, columns=columnas)

Método 3: Desde un archivo (lo más común)

# Leer desde CSV df = pd.read_csv('datos.csv') # Leer desde Excel df = pd.read_excel('datos.xlsx') # Leer desde JSON df = pd.read_json('datos.json')

Operaciones Básicas con DataFrames

👀

Explorar Datos

df.head() # Primeras 5 filas df.tail() # Últimas 5 filas df.info() # Información general df.describe() # Estadísticas
🔍

Seleccionar Datos

df['nombre'] # Una columna df[['nombre', 'edad']] # Varias columnas df[df['edad'] > 30] # Filtrar filas
📊

Agregar Datos

df['salario'].mean() # Promedio df['edad'].max() # Máximo df.groupby('ciudad') # Agrupar
🛠️

Modificar Datos

df['nuevo'] = 0 # Nueva columna df.drop('columna') # Eliminar columna df.fillna(0) # Rellenar nulos

Ejemplo práctico:

# Cargar datos df = pd.read_csv('ventas.csv') # Explorar print(f"Tenemos {len(df)} registros") print(f"Columnas: {list(df.columns)}") # Análisis básico print(f"Ventas promedio: {df['ventas'].mean():.2f}") print(f"Producto más vendido: {df['producto'].mode()[0]}") # Filtrar datos ventas_altas = df[df['ventas'] > 1000] print(f"Ventas altas: {len(ventas_altas)} registros")

📚 Conceptos importantes a recordar

  • Series: Array unidimensional con etiquetas (como una columna)
  • DataFrame: Tabla bidimensional (como una hoja de Excel)
  • Index: Etiquetas de las filas (por defecto 0, 1, 2, ...)
  • Columns: Nombres de las columnas
  • NaN: "Not a Number" - representa valores faltantes
